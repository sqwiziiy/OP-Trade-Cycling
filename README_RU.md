# OP Trade Cycling

[English](README.md)

Клиентский Fabric-мод для Minecraft **1.20.1**, который позволяет игроку с правом использовать ванильные команды `/data` безопасно обновлять сделки **непроторгованного** жителя без установки мода на сервер.

> Мод предназначен для серверов/миров, где тебе разрешены операторские команды. Он не обходит серверные права.

## Возможности

- Полностью client-only: на сервер ничего ставить не нужно.
- Работает в одиночке с читами и на сервере, если у игрока доступны `/data` и `/execute` (обычно permission level 2+).
- Работает только с точным UUID открытого жителя.
- При реролле окно торговли визуально остаётся открытым.
- Не даёт рероллить жителя, с которым уже торговали.
- Несколько уровней защиты: использованные сделки, XP жителя, блокировка UUID на сессию и серверный guard `Xp:0`.
- Нет опасного fallback на ближайшего жителя: если точный житель не определён, мод ничего не меняет.

## Требования

- Minecraft **1.20.1**
- Fabric Loader
- Fabric API
- Java 17+

## Использование

1. Установи мод и Fabric API **на клиент**.
2. Открой торговлю с непроторгованным жителем с профессией.
3. Нажми клавишу **«Обновить сделки жителя (OP)»**. По умолчанию это **C**, клавишу можно переназначить в настройках управления.
4. Сделки обновятся, а окно торговли переоткроется на месте.

Если житель уже был проторгован, мод откажется делать реролл.

## Сборка

```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk ./gradlew build
```

Готовый JAR появится в `build/libs/`.
