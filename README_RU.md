# OP Trade Cycling

[English](README.md)

Клиентский Fabric-мод для Minecraft **1.20.1**, который позволяет игроку с правом использовать ванильные команды `/data` обновлять сделки жителя без установки мода на сервер.

> Мод предназначен для серверов/миров, где тебе разрешены операторские команды. Он не обходит серверные права.

## Возможности

- Полностью client-only: на сервер ничего ставить не нужно.
- Работает в одиночке с читами и на сервере, если у игрока доступны `/data` и `/execute` (обычно permission level 2+).
- Работает только с точным UUID открытого жителя.
- При реролле окно торговли визуально остаётся открытым.
- По умолчанию не даёт рероллить жителя, с которым уже торговали.
- Есть отдельный опасный bypass-режим для намеренного полного сброса уже проторгованного жителя.
- В безопасном режиме используются несколько уровней защиты: использованные сделки, XP жителя, блокировка UUID на сессию и серверный guard `Xp:0`.
- Нет fallback на ближайшего жителя: если точный житель не определён, мод ничего не меняет.

## Требования

- Minecraft **1.20.1**
- Fabric Loader
- Fabric API
- Java 17+

## Использование

1. Установи мод и Fabric API **на клиент**.
2. Открой торговлю с жителем с профессией.
3. Нажми клавишу **«Обновить сделки жителя (OP)»**. По умолчанию это **C**, клавишу можно переназначить в настройках управления.
4. Сделки обновятся, а окно торговли переоткроется на месте.

## Опасный bypass

При первом запуске мод создаёт файл:

`config/optradecycling.json`

По умолчанию:

```json
{
  "dangerousBypassUsedTrades": false
}
```

При `false` работает нынешняя безопасная логика: если с жителем уже торговали, реролл запрещён.

Если поставить:

```json
{
  "dangerousBypassUsedTrades": true
}
```

защита от проторгованных жителей отключается. В этом режиме F10/назначенная клавиша может полностью сбросить торговый прогресс уже использованного жителя:

- старые сделки удаляются;
- торговый XP сбрасывается до `0`;
- уровень торговли сбрасывается до novice (1);
- для той же профессии генерируются новые сделки;
- gossip/репутация и связанные с ней скидки не удаляются.

Конфиг перечитывается при каждом нажатии клавиши реролла — перезапускать Minecraft после переключения не нужно.

**Внимание:** этот режим специально позволяет уничтожить ценные сделки и прогресс жителя. Включай его только когда именно этого и хочешь.

## Сборка

```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk ./gradlew build
```

Готовый JAR появится в `build/libs/`.
